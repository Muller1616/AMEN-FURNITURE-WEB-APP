# AMEN Furniture Web App

**AMEN Furniture** is a modern and responsive web application built to showcase furniture products with style and simplicity.  
The platform provides a clean browsing experience where users can explore furniture collections, view product details, and enjoy a smooth, visually appealing interface.

---

## Overview

This project was developed as part of a web development  to demonstrate strong frontend design, API Integration and modern UI implementation using **Next.js**, **Typescript** and **Tailwind CSS**.  
The goal is to deliver a fast, user-friendly, and responsive web application for an online furniture store.

---

## Features

- **Beautiful Home Page** – Highlights featured products and brand identity.  
- **Product Listing** – Displays furniture items with images, prices, and short descriptions.  
- **Product Details** – Provides in-depth information for each furniture item.  
- **Navigation System** – Simple and clean navigation across pages.  
- **Fully Responsive** – Adapts to desktop, tablet, and mobile screens.  
- **Optimized Performance** – Built using Next.js for speed and SEO benefits.

## Installation and Setup

To run the project locally:

1. Clone the repository
   ```bash
   git clone https://github.com/Muller1616/AMEN-FURNITURE-WEB-APP.git

2. Navigate into the project directory
     cd AMEN-FURNITURE-WEB-APP
3. Install dependencies
    npm install
4. Run the development server
    npm run dev
5. open the app in your browser
    http://localhost:3000
